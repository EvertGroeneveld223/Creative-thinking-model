# Project: Creativity engine ("Formula of Understanding and Creativity")

Read HANDOFF.md first. It has the goal, the state of every stage and the open problems. Results and their numbers are in CLAIMS.md.

## Rules for working here
- Python 3.14 (the project's .venv), standard library only (no installs needed). `python main.py` lists the project commands. Otherwise run a script from inside its own folder; paths are relative to the file.
- Never claim a period/explanation that was not computed. Tag numbers COMPUTED / SOURCED / DERIVED / CLAIMED.
- Do not type result numbers into HANDOFF.md. Add a claim to `claims.py`, which recomputes it, and cite its id. A test keeps the two in step.
- Before running a check whose result you do not know, commit your confidence: `python calibration/ledger.py commit P "claim" "check"`. Resolve it afterwards, whichever way it went. Never rewrite one.
- For a comparison, write a pre-registration first (see `s6_patches/PREREG_waves.md`): fixed seeds, fixed metric, no peeking.
- The test world (integer sequences mod m) was built by the assistant, so say so when reporting results.
- `waves4.py` writes a replayable log and no longer touches waves_base.json / waves_polar.json. Those two files are the older 2-run results.
- Novelty comes from s7_novelty/novelty.py, not from memory. n = 1 means "not found by the searches listed", and an unreachable source is UNCHECKED, never novel. An OEIS term match counts only after `compare()` on every listed term. Record a page you open by hand in `s8_proofs/opened_pages.json`, saying how much of it you read.
- A proof in s8_proofs/PROOFS.md has not been reviewed by a mathematician; say so when citing it. A rule that passes tests is a conjecture: it sets w, never e.
- PROMPT_PROGRESS.md (the project's state as one prompt for another LLM) is generated by `make_prompt.py`, which `claims.py` runs too. Edit PROMPT_TEMPLATE.md, never the output, and type no result numbers in the template.
- Tests: `python main.py tests`. Proof checks: `python main.py proofs`. Claims: `python main.py claims`.
- Next work is listed under "Open problems" in HANDOFF.md. Start from there unless the user says otherwise.
